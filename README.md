# Ulu Team Portal 0.4.0 for Mac

Download the desktop app for your Mac. Requires **macOS 13 or newer** and an authorized Ulu Team Portal account.

| Your Mac | Download |
| --- | --- |
| Apple silicon — M1 or newer | [Download for Apple silicon](https://github.com/the-ulu-team/portal-desktop-downloads/releases/download/v0.4.0/Ulu-Team-Portal-0.4.0-mac-arm64.dmg) |
| Intel | [Download for Intel Mac](https://github.com/the-ulu-team/portal-desktop-downloads/releases/download/v0.4.0/Ulu-Team-Portal-0.4.0-mac-x64.dmg) |

Check **Apple menu → About This Mac** if you are unsure which version to choose. Both apps are signed with Apple Developer ID and notarized by Apple.

## Install or update

1. Quit Ulu Team Portal.
2. Open the downloaded DMG and drag **Ulu Team Portal** into **Applications**. Replace the older copy if prompted.
3. Open the app from Applications and sign in if asked. Google sign-in opens your browser and returns to the app.

Existing test builds need this first manual upgrade. This release prepares desktop update checks and prompts; Portal web features continue to update separately.
